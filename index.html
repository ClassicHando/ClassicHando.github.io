Welcome to ClassicHando's Financial Friend!

To use as intended, follow the directions on each page at this location.

When you're done, hit the Next button in the bottom-right corner!

If you know what you'd like to do, you can use the tabs on the left side of the page (or the top if that's where they ended up!) to navigate to whichever tool you would like to use.

This is a polished version of the tool I created and used when I was a Financial Counselor. I developed this initially to aid my learning but then it spiralled into a tool that I used to help clients and was optioned by the institution I was with.

I felt this tool is useful and needs to be out there, so I developed it on my own time and am releasing it free of charge as an independent developer for anybody to use!

If you'd like to help me stay independent, hit that donate button over there! If you can't or just don't want to, don't worry about it! I hope this tool helps!
